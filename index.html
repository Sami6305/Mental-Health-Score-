About This Project

Mental Health AI is a portfolio project that demonstrates machine learning-based score prediction. A trained regression model receives lifestyle and social media usage details and returns a numeric mental health score estimate through a FastAPI service.

The model has not been clinically validated. Results are for demonstration and learning purposes only and should not be used to make health decisions.
